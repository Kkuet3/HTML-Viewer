Cookie policy

Necessary preferences and optional analytics

The editor uses local browser storage for core preferences. Optional measurement is separated behind the consent controls shown on the main application.

Necessary local preferences

HTML Viewer stores functional settings such as visual theme, panel split, language and consent state. These values make the application consistent between visits and do not create a user account.

Analytics

The analytics category helps measure aggregate usage and diagnose performance. The Google Tag Manager container is loaded only after analytics or marketing consent is granted. Rejecting optional categories leaves the local editor features available.

Marketing

The consent interface includes a marketing category for Google Consent Mode compatibility. HTML Viewer does not claim that a marketing technology is active merely because the category exists; behavior also depends on the tags configured inside the consented container.

External resources are not all cookies

Fonts and editor libraries can make ordinary network requests even when they do not store an analytics cookie. The privacy policy describes those website resources separately from optional analytics and from user-written project code.

Changing a choice

Use the Cookies link in the application sidebar to reopen the settings. Browser site-data controls can also remove stored preferences. If preferences are cleared, the consent banner will appear again on the next visit.
