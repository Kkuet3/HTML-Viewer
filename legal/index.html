Legal notice and conditions of use

This page identifies the purpose and operating boundaries of HTML Viewer. It complements the privacy and cookie policies.

Service description

HTML Viewer is a browser-based editor and preview tool for HTML, CSS, JavaScript and related static project assets. User-written code is processed locally by browser APIs. The service does not provide user accounts, cloud project hosting or a backend deployment environment.

Acceptable use

Use the editor only with code and files that you are entitled to process. Do not use the service to create, test or distribute unlawful, malicious or rights-infringing material. Previewed code can execute in the browser; users remain responsible for understanding and trusting the code they run.

Availability and warranties

The tool is provided free of charge and may change as browsers and web-platform APIs evolve. Reasonable effort is made to preserve project previews and exports, but users should keep their own copies and validate exported files before relying on them. The service is not a substitute for a production hosting environment, security review or backup system.

Third-party resources

The website may request third-party resources such as fonts, editor libraries or consented analytics. Their availability and policies are controlled by their respective providers. See the privacy policy and cookie policy.
