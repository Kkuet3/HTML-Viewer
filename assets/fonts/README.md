# Local UI fonts

These WOFF2 files are the Latin subsets used by the HTML Viewer interface:

- `inter-latin-v20.woff2` — Inter v20, weights 400/500/700.
- `outfit-latin-v15.woff2` — Outfit v15, weight 700.
- `jetbrains-mono-latin-v24.woff2` — JetBrains Mono v24, weights 400/500.

They were obtained from the versioned Google Fonts static URLs previously used
by `index.html`. Each family is distributed under the SIL Open Font License;
the corresponding license text is stored beside the font files.
