Dos formas de trabajar, una vista previa rápida

Simple está pensado para fragmentos, ejercicios y páginas autocontenidas. El código se actualiza directamente en el visor, por lo que resulta práctico para aprender etiquetas HTML, ajustar CSS o comprobar una pequeña interacción de JavaScript. Archivos se acerca más a un proyecto estático real: mantiene documentos separados, carpetas y recursos locales, y permite elegir qué HTML funciona como entrada de la vista previa.

No hay que compilar ni configurar dependencias. Puedes empezar con una página vacía, cargar un ejemplo, soltar un archivo HTML o importar un ZIP. Los controles de escritorio, tablet y móvil ayudan a revisar rápidamente cómo responde el diseño en distintos anchos.

HTML, CSS y JavaScript en el mismo flujo

En modo Simple puedes escribir un documento completo con estilos y scripts incluidos. En modo Archivos puedes enlazar `styles.css`, `script.js`, fuentes, imágenes y otros recursos mediante rutas relativas. La vista previa conserva esa estructura y el exportador puede descargar el proyecto como ZIP o compilarlo como un único HTML cuando necesitas compartir un resultado autocontenido.

El editor Monaco aporta resaltado de sintaxis, selección, búsqueda y atajos conocidos. Mientras se carga, existe un editor básico de respaldo para que la página no dependa de una descarga grande antes de aceptar texto.

Privacidad: qué permanece local y qué usa servicios externos

El código que escribes y los archivos que importas se procesan dentro de tu navegador. HTML Viewer no necesita una cuenta ni guarda proyectos en una base de datos propia. Puedes exportar el trabajo para conservarlo localmente.

La web sí puede solicitar recursos externos, como tipografías o la biblioteca del editor, y sólo activa la analítica opcional cuando das consentimiento. Esta separación evita la promesa ambigua de que el navegador no realiza ninguna conexión: lo importante es que el contenido de tu proyecto no se sube como proyecto alojado. Consulta la política de privacidad y la política de cookies para ver los detalles.

Casos de uso habituales

Aprender desarrollo web

Prueba etiquetas semánticas, selectores CSS y eventos de JavaScript con una respuesta visual inmediata.

Prototipar una interfaz

Monta una idea, comprueba estados responsive y comparte un HTML unificado sin preparar un proyecto complejo.

Revisar un proyecto

Importa un ZIP, navega por sus archivos, corrige rutas y vuelve a exportar el resultado conservando la estructura.

Cómo empezar

  1. Abre el editor. El modo Simple aparece listo para escribir sin registro.
  2. Escribe o importa. Pega un documento, suelta un HTML o cambia a Archivos para cargar un ZIP.
  3. Comprueba la vista. Alterna entre código y preview en móvil, o usa los paneles simultáneos en escritorio.
  4. Exporta. Descarga el HTML, el ZIP o una versión unificada según el tipo de proyecto.

Preguntas rápidas

¿Es realmente gratuito?

Sí. El editor no exige registro ni un plan de pago.

¿Puedo usar imágenes y carpetas?

Sí. El modo Archivos admite una estructura de proyecto con recursos y rutas relativas.

¿Funciona sin conexión?

Tras la carga inicial, las funciones locales principales pueden seguir disponibles. Algunos recursos opcionales alojados externamente requieren conexión si todavía no están en caché.

La interfaz del editor selecciona español automáticamente cuando el navegador está en español. El enlace “Abrir editor” también fuerza el idioma con `?lang=es`.
